A language model with 0.6 billion parameters that can think before it answers, small enough for a laptop CPU.

Qwen3-0.6B is a 0.6-billion-parameter member of the Qwen3 family. It is an open-weight text model released under Apache 2.0, so it can also be used in commercial projects.

🔧 **Type:** text generation. Decoder-only transformer with grouped-query attention, 28 layers. Thinking mode is on by default and can be turned off per request. Used from Python with `transformers`.
📏 **Size:** 0.6B parameters, 32,768-token context, about 1.5 GB of BF16 weights.
💻 **Minimum hardware:** CPU with about 2 GB of RAM, or about 2 GB of VRAM on a GPU *(our estimate, not stated in the model card)*.
🛠️ **Interfaces:** Python (`transformers`), SGLang and vLLM for an OpenAI-compatible API, and local apps such as Ollama and llama.cpp.
🏢 **Behind it:** Qwen Team. The model card cites the Qwen3 technical report (arXiv:2505.09388).

Our families for this one: Starter · NU tier · Text · Transformer decoder · Qwen2.5 → Qwen3 line.

Model card: https://huggingface.co/Qwen/Qwen3-0.6B
