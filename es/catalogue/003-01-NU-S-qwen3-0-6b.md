Un modelo de lenguaje de 0,6 mil millones de parámetros que puede razonar antes de responder, y que cabe en la CPU de un portátil.

Qwen3-0.6B es un miembro de 0,6 mil millones de parámetros de la familia Qwen3. Es un modelo de texto de pesos abiertos, con licencia Apache 2.0, así que también se puede usar en proyectos comerciales.

🔧 **Tipo:** generación de texto. Transformer solo decodificador con atención agrupada (GQA), 28 capas. El modo de razonamiento está activado por defecto y se puede desactivar por petición. Se usa desde Python con `transformers`.
📏 **Tamaño:** 0,6 mil millones de parámetros, contexto de 32.768 tokens, unos 1,5 GB de pesos en BF16.
💻 **Hardware mínimo:** CPU con unos 2 GB de RAM, o unos 2 GB de VRAM en GPU (estimación nuestra, no la indica la ficha del modelo).
🛠️ **Interfaces:** Python (`transformers`), SGLang y vLLM para una API compatible con OpenAI, y aplicaciones locales como Ollama o llama.cpp.
🏢 **Detrás del modelo:** Qwen Team. La ficha cita el informe técnico de Qwen3 (arXiv:2505.09388).

Nuestras familias para este: Starter · NU · Texto · Transformer decoder · línea Qwen2.5 → Qwen3.

Ficha del modelo: https://huggingface.co/Qwen/Qwen3-0.6B
