Un asistente de IA que se ejecuta en tu propio ordenador y responde en las aplicaciones de mensajería que ya usas.

OpenClaw es un asistente de código abierto (licencia MIT). Un Gateway local lo conecta con canales como Telegram, WhatsApp, Slack o Discord, y los modelos que usa, en la nube o en local, son plugins que se pueden cambiar.

🔧 **Tipo:** gateway de asistente de IA (no es un modelo). Paquete de Node.js, instalado con un script de instalación o con `npm`.
📏 **Tamaño:** el paquete npm se llama `openclaw`. Nuestra instalación de prueba usó unos 400 MB de RAM para el proceso del Gateway en una Raspberry Pi 5.
💻 **Hardware mínimo:** una versión de Node.js compatible (los metadatos de npm exigen 24.16.0 o posterior en la rama 24.x, o 26.1.0 o posterior). El README no da una cifra de hardware; nuestra máquina de prueba fue una Raspberry Pi 5 de 8 GB de RAM.
🛠️ **Interfaces:** canales de mensajería, una Control UI en el navegador, la línea de comandos `openclaw` y una interfaz de terminal.
🏢 **Detrás:** OpenClaw Foundation, con un repositorio público en GitHub.

Nuestras familias para este: Starter · tier NU (provisional, es un asistente, no un modelo) · Texto.
