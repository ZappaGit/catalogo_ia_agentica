## Qué es

Qwen3-0.6B es un modelo de lenguaje (generación de texto) de la serie Qwen3. Responde a instrucciones, puede razonar paso a paso en matemáticas y código, y puede usar herramientas externas según la ficha. Es un modelo de chat ya entrenado (post-entrenamiento), no el modelo base sin ajustar.

## Tipo y tecnología

- **Tarea:** generación de texto (chat, razonamiento, uso de herramientas).
- **Arquitectura:** causal decoder-only, con atención GQA. 28 capas, 16 cabezas de consulta y 8 de clave/valor, dimensión oculta de 1.024 (ficha y `config.json`).
- **Embeddings compartidos:** `tie_word_embeddings: true`, es decir, la capa de entrada y la de salida comparten pesos (`config.json`).
- **Lenguaje de implementación:** Python, sobre PyTorch a través de `transformers` (la ficha pide `transformers` ≥ 4.51.0; con versiones anteriores aparece `KeyError: 'qwen3'`).

## Tamaño

- **Parámetros:** 0,6 B según la ficha; 0,44 B sin embeddings.
- **Contexto:** 32.768 tokens (ficha). La ficha no indica una extensión con YaRN para este modelo, a diferencia del de 8.000 millones.
- **Formato:** safetensors, BF16, un único archivo `model.safetensors` de 1.503.300.328 bytes (≈ 1,5 GB).

- Ollama, LM Studio, MLX-LM, llama.cpp y KTransformers, según la ficha.
- La ficha también menciona un endpoint de Alibaba Model Studio (de pago). No se ha usado ni se recomienda como parte de esta serie.

## Quién lo usa y para qué

- La ficha no cita proyectos ni empresas concretas.
- Dato de popularidad (snapshot 2026-11-06): 21.472.241 descargas y 1.881 "me gusta" en Hugging Face.

## Por qué importa

Tiene el mismo interruptor de razonamiento que el 8B (`enable_thinking`, y `/think` y `/no_think` en el mensaje), con un tamaño que, según nuestra estimación, permite probar el flujo completo en un equipo sin GPU.

## Quién está detrás

- **Organización:** Qwen Team; la ficha del modelo menciona Alibaba.
- **Autores:** la ficha cita el informe técnico de Qwen3 (arXiv:2505.09388), firmado como "Qwen Team". Los autores individuales no aparecen en la ficha.

## Curiosidades

- Con `enable_thinking=True`, la ficha indica que la salida siempre incluye un bloque `<think>...</think>`, aunque su contenido esté vacío si se desactiva el razonamiento con `/no_think`. Con `enable_thinking=False`, los interruptores `/think` y `/no_think` no tienen efecto.
- La ficha recomienda para el modo de razonamiento los mismos parámetros de muestreo que el modelo de 8.000 millones (Temperature 0,6, TopP 0,95, TopK 20), y advierte de no usar decodificación voraz (greedy).

## Cómo ejecutarlo

**Estado: untested.** Los comandos se han comprobado contra la ficha del modelo y el índice de PyPI (los paquetes existen), pero no se han ejecutado. No se ha descargado ningún peso ni se ha ejecutado el ejemplo.

### a. Requisitos previos

- Python 3.10 o superior (el equipo tiene Python 3.12.10).
- Windows 11. Este modelo funciona en CPU; una GPU NVIDIA con CUDA es opcional.
- Unos 4 GB de RAM libres para la prueba en CPU.
- Opcional: WSL 2 con Ubuntu.

### b. Entorno virtual

PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Git Bash:

```bash
python -m venv .venv
source .venv/Scripts/activate
```

WSL (Ubuntu):

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### c. Instalación

```powershell
python -m pip install --upgrade pip
pip install torch
pip install "transformers>=4.51.0" accelerate
```

`torch` por defecto es la versión de CPU en Windows, que basta para este modelo. Para usar GPU, elige la build de CUDA en https://pytorch.org. `accelerate` es necesario para `device_map="auto"`.

### d. Ejemplo mínimo

Guárdalo como `run_qwen3_06b.py` fuera del proyecto (por ejemplo, en la carpeta scratchpad), no en el Python global:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "Qwen/Qwen3-0.6B"

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype="auto",
    device_map="auto",
)

messages = [{"role": "user", "content": "Give me a short introduction to large language models in two sentences."}]
text = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True,
    enable_thinking=False,  # sin bloque de razonamiento, respuesta más corta
)
inputs = tokenizer([text], return_tensors="pt").to(model.device)

output_ids = model.generate(**inputs, max_new_tokens=128)
new_tokens = output_ids[0][len(inputs.input_ids[0]):]
print(tokenizer.decode(new_tokens, skip_special_tokens=True).strip())
```

Ejecución:

```powershell
python run_qwen3_06b.py
```

La ficha no está protegida (`gated: false`), así que no hace falta token de Hugging Face. Si tienes uno, define la variable en la sesión, nunca en el código:

```powershell
$env:HF_TOKEN = "<tu-token>"
```

### e. Comprobación

La salida esperada son dos frases sobre modelos de lenguaje, sin etiquetas `<think>`, porque el razonamiento está desactivado en el ejemplo. Si la salida está vacía o el proceso se queda sin memoria, revisa las advertencias.

### f. Advertencias

- **Descarga:** unos 1,5 GB de pesos en BF16, en la caché de Hugging Face (`%USERPROFILE%\.cache\huggingface`).
- **Licencia:** Apache 2.0. No hace falta aceptar ninguna condición en Hugging Face.
- **Hardware:** el ejemplo corre en CPU sin GPU. La primera carga tarda más por la descarga.
- **Razonamiento:** si activas el modo de razonamiento (`enable_thinking=True`, que es el valor por defecto), la salida es mucho más larga; sube `max_new_tokens` (la ficha sugiere hasta 32.768).
