## What it is

Qwen3-0.6B is a language model (text generation) from the Qwen3 series. It responds to instructions, can reason step by step in mathematics and code, and can use external tools according to the model card. It is a chat model that has already been trained (post-training), not the untuned base model.

## Type and technology

- **Task:** text generation (chat, reasoning, tool use).
- **Architecture:** causal decoder-only, with GQA attention. 28 layers, 16 query heads and 8 key/value heads, hidden dimension of 1,024 (model card and `config.json`).
- **Shared embeddings:** `tie_word_embeddings: true`, meaning the input and output layers share weights (`config.json`).
- **Implementation language:** Python, on PyTorch through `transformers` (the model card requires `transformers` ≥ 4.51.0; with earlier versions the error `KeyError: 'qwen3'` appears).

## Size

- **Parameters:** 0.6 B according to the model card; 0.44 B without embeddings.
- **Context:** 32,768 tokens (model card). The model card does not indicate a YaRN extension for this model, unlike the 8-billion-parameter one.
- **Format:** safetensors, BF16, a single file `model.safetensors` of 1,503,300,328 bytes (≈ 1.5 GB).

## Minimum hardware

| Precision | Weights | With 20–30 % margin | Reference |
|-----------|---------|---------------------|-----------|
| BF16 / FP16 | 0.752 B × 2 B ≈ 1.50 GB | ≈ 1.8–2.0 GB | GPU with 4 GB of VRAM, or CPU with 4 GB of RAM |
| INT8 | 0.752 B × 1 B ≈ 0.75 GB | ≈ 0.9–1.0 GB | GPU with 2 GB of VRAM |
| INT4 | 0.752 B × 0.5 B ≈ 0.38 GB | ≈ 0.45–0.5 GB | Laptop without GPU |

For the calculation the parameter count from the file (751,632,384) is used, which the Hugging Face API sums for the whole model. Long context adds KV cache memory. These are estimates; the real measurement depends on the environment.

## Interfaces

- `transformers` (`AutoModelForCausalLM`, `AutoTokenizer`).
- SGLang (`sglang>=0.4.6.post1`) and vLLM (`vllm>=0.8.5`) for an OpenAI-compatible API.
- Ollama, LM Studio, MLX-LM, llama.cpp and KTransformers, according to the model card.
- The model card also mentions an Alibaba Model Studio endpoint (paid). It has not been used and is not recommended as part of this series.

## Who uses it and for what

- The model card does not cite specific projects or companies.
- Popularity figure (snapshot 2026-11-06): 21,472,241 downloads and 1,881 likes on Hugging Face.

## Why it matters

It has the same reasoning switch as the 8B model (`enable_thinking`, and `/think` and `/no_think` in the message), at a size that, by our estimate, makes it possible to test the full workflow on a machine without a GPU.

## Behind the model

- **Organization:** Qwen Team; the model card mentions Alibaba.
- **Authors:** the model card cites the Qwen3 technical report (arXiv:2505.09388), signed as "Qwen Team". Individual authors do not appear in the model card.

## Curiosities

- With `enable_thinking=True`, the model card states that the output always includes a `<think>...</think>` block, although its content is empty if reasoning is turned off with `/no_think`. With `enable_thinking=False`, the `/think` and `/no_think` switches have no effect.
- For reasoning mode, the model card recommends the same sampling parameters as the 8-billion-parameter model (Temperature 0.6, TopP 0.95, TopK 20), and warns against greedy decoding.

## How to run it

**Status: untested.** The commands were checked against the model card and the PyPI index (the packages exist), but they have not been run. No weights have been downloaded and the example has not been executed.

### a. Prerequisites

- Python 3.10 or newer (the machine has Python 3.12.10).
- Windows 11. This model runs on CPU; an NVIDIA GPU with CUDA is optional.
- About 4 GB of free RAM for the CPU test.
- Optional: WSL 2 with Ubuntu.

### b. Virtual environment

PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Git Bash:

```bash
python -m venv .venv
source .venv/Scripts/activate
```

WSL (Ubuntu):

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### c. Installation

```powershell
python -m pip install --upgrade pip
pip install torch
pip install "transformers>=4.51.0" accelerate
```

On Windows, `torch` installs the CPU version by default, which is enough for this model. To use a GPU, choose the CUDA build at https://pytorch.org. `accelerate` is required for `device_map="auto"`.

### d. Minimal example

Save it as `run_qwen3_06b.py` outside the project (for example, in the scratchpad folder), not in the global Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "Qwen/Qwen3-0.6B"

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype="auto",
    device_map="auto",
)

messages = [{"role": "user", "content": "Give me a short introduction to large language models in two sentences."}]
text = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True,
    enable_thinking=False,  # no reasoning block, shorter answer
)
inputs = tokenizer([text], return_tensors="pt").to(model.device)

output_ids = model.generate(**inputs, max_new_tokens=128)
new_tokens = output_ids[0][len(inputs.input_ids[0]):]
print(tokenizer.decode(new_tokens, skip_special_tokens=True).strip())
```

Run:

```powershell
python run_qwen3_06b.py
```

The model card is not gated (`gated: false`), so no Hugging Face token is needed. If you have one, set the variable in the session, never in the code:

```powershell
$env:HF_TOKEN = "<your-token>"
```

### e. Check

The expected output is two sentences about language models, without `<think>` tags, because reasoning is turned off in the example. If the output is empty or the process runs out of memory, check the warnings.

### f. Warnings

- **Download:** about 1.5 GB of BF16 weights, in the Hugging Face cache (`%USERPROFILE%\.cache\huggingface`).
- **License:** Apache 2.0. No terms need to be accepted on Hugging Face.
- **Hardware:** the example runs on CPU without a GPU. The first load takes longer because of the download.
- **Reasoning:** if you turn on reasoning mode (`enable_thinking=True`, the default), the output is much longer; raise `max_new_tokens` (the model card suggests up to 32,768).
